# graphicle-ai/.github

This repository holds the profile of the graphicle-ai organisation
([profile/README.md](profile/README.md)) and the default community files that
every repository of the organisation uses unless it has its own: the issue
forms, the discussion forms, the pull request template, SUPPORT.md and
SECURITY.md (all in [.github/](.github/)).

Graphicle itself lives in
[graphicle-ai/graphicle](https://github.com/graphicle-ai/graphicle).
